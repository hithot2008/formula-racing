# 遊戲設計規格

[English](GAME_DESIGN.en.md)

<!-- section: section-00 -->

本文件保留完整設計目標，不代表所有功能均已完成。目前已採用 Three.js + Vite 的本機瀏覽器版本；實作狀態與限制請見 [開發狀態](ROADMAP.md)。

<!-- section: section-01 -->

## 定位

現代寫實的 3D 方程式賽車遊戲。核心體驗是煞車重量轉移、彎中抓地極限及出彎加速控制。電腦單人完整體驗優先，現階段平台為本機瀏覽器。

<!-- section: section-02 -->

## 美術與聲音

寫實車體、碳纖維與金屬、輪胎磨耗、動態陰影、雨滴與水霧。場景包括維修區、看台、緩衝区及日夜天候。支援座艙、車頂、追車及回放鏡頭。HUD 顯示速度、檔位、圈速差、輪胎、能源及旗號。引擎、換檔、輪胎、路緣與工程師聲音提供駕駛回饋；震動與速度模糊可調整。

<!-- section: section-03 -->

## 物理核心

採固定時間步長，物理與渲染更新分開；第一版使用可調校的簡化輪胎模型。

| 系統 | 模擬內容 |
| --- | --- |
| 輪胎 | 胎溫、磨耗、濕度、縱向與橫向抓地分配 |
| 車身 | 加減速與轉向重量轉移、重心及慣性 |
| 空力 | 隨速度變化的下壓力與風阻 |
| 懸吊 | 彈簧、阻尼、路緣及底盤接地 |
| 動力 | 扭力曲線、檔位、引擎煞車 |
| 制動 | 前後分配、鎖死與溫度 |
| 車損 | 前翼、輪胎、懸吊損傷對操控的影響 |
| 天候 | 濕地抓地、積水及乾燥路線 |

不以車隊工程模擬精度作為初版承諾。以一致、可解釋的操控和可測量的物理行為驗收。

<!-- section: section-04 -->

## 難度

| 項目 | 容易 | 進階 | 專業 |
| --- | --- | --- | --- |
| 輔助 | 自動換檔、防鎖死、循跡、穩定 | 可逐步關閉 | 預設關閉主要輔助 |
| 賽車線 | 完整引導 | 可選彎道提示 | 預設關閉 |
| AI | 慢節奏、較大避讓 | 積極竞争、偶有失誤 | 穩定圈速與戰術 |
| 車損 | 輕微影響 | 部件影響操控 | 嚴重損傷可退賽 |
| 規則 | 提醒為主 | 主要處罰 | 完整旗號及限制 |
| 策略 | 自動管理 | 部分自行管理 | 完整管理 |
| 補救 | 倒帶與重試 | 可限制倒帶 | 排名挑戰停用倒帶 |

支援自訂輔助與 AI 強度；排行榜按輔助設定分組。AI 使用與玩家一致的車輛限制，不以隱藏加速調整難度。

## 賽道與關卡

| 賽道 | 特性 | 學習目標 |
| --- | --- | --- |
| 新秀測試場 | 寬廣短賽道 | 基本轉向與煞車 |
| 海岸賽道 | 中速彎與直線 | 煞車點與出彎 |
| 山丘賽道 | 高低差、盲彎 | 重量轉移 |
| 森林高速賽道 | 高速連續彎 | 下壓力與節奏 |
| 港灣街道賽 | 狹窄護牆 | 精準走線與超車 |
| 沙漠大獎賽 | 高溫高磨耗 | 輪胎與進站策略 |
| 雨中技術賽道 | 低抓地、變天 | 油門與換胎時機 |
| 都會夜間決賽 | 複合彎、長距離 | 綜合駕駛與策略 |

每條賽道包含技巧、計時及正式賽事三種主線挑戰，共 24 個。計時設銅銀金牌與個人幽靈車。

<!-- section: section-06 -->

## 模式與比賽流程

模式：駕駛學院、快速比賽、計時賽、錦標賽、生涯。

流程：選擇賽事 → 調校 → 練習 → 排位 → 正賽 → 成績與分析。

完整目標包含起跑燈、搶跑、檢查點、計圈、名次、AI 跟車超車避碰、換胎維修、能源回收、超車輔助區、黃旗藍旗、賽道限制及時間處罰。暫停、重試、設定、自動存檔和賽後圈速分析為基本功能。生涯解鎖賽事、塗裝與調校選項。

<!-- section: section-07 -->

## 技術架構與平台

模組：車輛物理、輸入與輔助、AI、賽事規則、渲染場景、介面、存檔。賽道與難度以資料配置管理。

完整目標建議桌面版；瀏覽器原型可驗證手感，但需控制畫面、車流及周邊支援。優先鍵盤及手把；方向盤與力回饋依平台評估。目前使用 Three.js + Vite；原生桌面包裝仍待評估。
