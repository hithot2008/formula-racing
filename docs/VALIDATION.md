# v0.1 驗證紀錄

日期：2026-09-03。環境：macOS、Node.js 22.15.1、Google Chrome、Playwright。瀏覽器測試使用軟體 WebGL；未據此聲稱實機 GPU 的目標幀率。

## 通過

- 7 項 Node 測試：8 條閉合賽道、加速與煞停、濕地延長煞停距離、30/60 FPS 固定步長一致性、回正處罰、碰撞分離、AI 在 8 條賽道完成單圈。
- Chrome 真實 DOM／鍵盤操作：選關、倒數、6 車起跑、加速、暫停凍結模擬、鏡頭切換、回正 +5 秒、操作指南、設定保存。
- 使用開發模式的固定步長驗證入口跑完 3 圈大獎賽、2 圈計時和 1 圈技巧挑戰；確認結果介面、最佳有效圈與幽靈車存檔。
- 1440 × 1000 桌面畫面截圖及 390 × 844 手機選單截圖；選單沒有橫向溢出。
- 無未捕捉 JavaScript 頁面錯誤。
- `npm run build` 成功；引擎拆分為獨立載入區塊。
- 更新 Vite 至 6.4.3 後，npm 安裝稽核回報 0 個漏洞。

截圖位於 `artifacts/`，物理測試位於 `tests/physics.test.js`，瀏覽器驗證位於 `tests/browser.mjs`。

## 驗證邊界

完整賽事測試採程式控制駕駛並加速模擬時間，並非真人手動跑完全程。尚未實測方向盤、實體手把、手機觸控裝置、Safari 或最低硬體效能。維修格已實作，但未包含於這輪自動瀏覽器互動測試。不同天候的物理及賽道可完賽性經模型測試，並不代表所有場景都通過完整美術驗收。
