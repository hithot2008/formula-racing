# Formula Racing

現代寫實風格的 3D 方程式賽車遊戲專案。

## 專案狀態

目前完成設計規劃與專案初始化，尚未實作可遊玩的遊戲。平台與引擎待選定；完整目標以電腦單人遊戲為主。

## 設計目標

- 注重輪胎抓地、重量轉移、空氣力學與煞車效果。
- 容易、進階、專業三種難度共用物理核心，以輔助與規則區分。
- 完整版本目標：8 條原創賽道、24 個挑戰及生涯模式。
- 首個可玩里程碑：1 輛車、1 條賽道、5 名 AI 對手、3 種難度。
